# Wolf Expansion branding assets

`wolf-expansion-logo.png` is the finalized user-provided branding source and must not be redrawn or substituted.

`wolf-expansion-mark.png` is a transparent, square crop of the wolf mark from that source. The PNGs under `icons/` are deterministic downscaled copies used by Firefox metadata and the settings interfaces:

- 16×16
- 32×32
- 48×48
- 96×96
- 128×128

These branding assets are separate from the original monochrome `currentColor` SVG controls used inside the ChatGPT sidebar.
